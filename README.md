#  Sudoku Pro

> A premium Sudoku web application built with React, TypeScript, Tailwind CSS, and Framer Motion, featuring intelligent puzzle generation, real-time number tracking, smooth animations, notes mode, hints, statistics, and a modern responsive UI.

---

##  Overview

Sudoku Pro is designed to deliver a **premium Sudoku experience** with an elegant interface, smooth micro-interactions, and intelligent gameplay mechanics.

Unlike traditional Sudoku websites, this project emphasizes **modern UI/UX**, responsive design, accessibility, and polished animations while maintaining the classic Sudoku rules.

Whether you're a beginner or an experienced Sudoku player, Sudoku Pro offers an enjoyable and immersive puzzle-solving experience.

##  Sudoku Rules

Sudoku is played on a **9×9 grid** divided into **nine 3×3 blocks**.

The objective is to fill every empty cell using numbers **1–9** while following these rules:

- Each **row** must contain every number from **1–9** exactly once.
- Each **column** must contain every number from **1–9** exactly once.
- Each **3×3 block** must contain every number from **1–9** exactly once.
- No duplicate numbers are allowed in any row, column, or block.

##  Installation

Clone the repository

```bash
git clone https://github.com/your-username/Sudoku-Pro.git
```

Navigate into the project

```bash
cd Sudoku-Pro
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
